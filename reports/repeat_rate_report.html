3) Insights หลัก

🔴 ปัญหาหลักไม่ใช่ "token ไม่พอ" แต่คือ "ใช้ไม่ถึง" 90% ของ churn cycles (120 จาก 133) เลิกทั้งที่ยังเหลือ token — utilization เฉลี่ยแค่ 25.1% และทิ้ง token เฉลี่ย 12.3M ต่อคน ตอนหมดอายุ → คอขวดอยู่ที่ engagement/activation ไม่ใช่ขนาด quota รวม token ถูก claw back ตอนหมดอายุทั้งหมด ~1.53B token
🟠 แต่คนที่ "ใช้จริง" ใช้หมดเร็วมาก — โอกาส upsell กลุ่มที่ใช้หมด (28 cycles) ใช้หมดเฉลี่ยภายใน 7.9 วัน จากรอบ ~30 วัน — ในจำนวนนี้ 10 cycles ยอมจ่ายซื้อใหม่กลางรอบทันที (ซื้อซ้ำเฉลี่ยที่วันที่ 11.8 ของรอบ) และ 5 cycles เลือก "รอ reset" แทนการจ่าย → เสนอ top-up / upgrade อัตโนมัติเมื่อใช้ถึง 80%
🟢 Repeat buyer มีมูลค่าสูงกว่าชัดเจน ลูกค้าซื้อซ้ำสร้างรายได้เฉลี่ย ฿1,303/คน เทียบกับซื้อครั้งเดียว ฿555/คน (2.3 เท่า) รายได้รวมประมาณการ (list price) ฿193,413 · ต้นทุน AI serving ฿29,475 (~15%) → margin สุขภาพดี ทุก 1% ของ repeat rate ที่เพิ่มได้ ≈ มูลค่าเพิ่มระยะยาวที่มีนัยยะ
🔵 Repeat rate จริงยังเร็วเกินตัดสิน — ประวัติการขายเพิ่ง ~3 เดือน Cohort เม.ย. (แก่สุด, 54 คน) repeat 5.6% · พ.ค. 2.4% · มิ.ย. 1.3% (ยังไม่ครบเวลา) — 228 จาก 449 paid cycles ยัง active อยู่ แนะนำติดตาม mature repeat rate (ตอนนี้ 3.64%) เป็น KPI รายเดือน

6) ข้อเสนอแนะเชิงปฏิบัติ (เรียงตาม impact)

#Actionกลุ่มเป้าหมายเหตุผลจากข้อมูล
1Activation program — onboarding, use-case nudge, แจ้งเตือนก่อนหมดอายุ 7 วัน ④ ใช้ไม่หมด+churn (120 cycles, 54%)กลุ่มใหญ่สุด เลิกทั้งที่ใช้แค่ 25% — ต้นเหตุ churn อันดับ 1
2Smart upsell — แจ้งเตือนเมื่อใช้ถึง 80% + เสนอ upgrade/top-up ในคลิกเดียว ①+③ ใช้หมดเร็ว (14 users)ใช้หมดใน ~8 วัน มี willingness-to-pay อยู่แล้ว (10 cycles จ่ายเองโดยไม่ต้องกระตุ้น)
3Win-back campaign — คูปอง/ส่วนลดหลังหมดอายุ ≤14 วัน churned 110 คนมี 41 users เคยกลับมาซื้อหลังหมดอายุเองตามธรรมชาติ — แปลว่า win-back ได้ผล
4ทบทวน trial design — ลด quota trial / จำกัดวัน / เพิ่ม friction ที่มีความหมาย trial 4,852 คนtrial→paid แค่ 1.44% และ trial ใช้เฉลี่ยแค่ 18.5% — trial ปัจจุบันอาจ "ให้ฟรีเกินจนไม่ต้องซื้อ" หรือไม่ engage
5Rollover incentive — ให้ token ที่เหลือ carry over บางส่วนเมื่อต่ออายุ ทุก paid usertoken 1.53B ถูกริบตอนหมดอายุ → "จ่ายแล้วไม่ได้ใช้" เป็น friction ต่อการซื้อซ้ำ
6ตั้ง KPI: mature repeat rate — วัดเฉพาะ cohort ที่ซื้อครั้งแรก ≥35 วัน ทีม analyticsตัวเลขรวม (2.37%) ต่ำเทียมเพราะครึ่งหนึ่งของ cohort ยังไม่ถึงเวลาตัดสิน

7) ข้อจำกัดของการวิเคราะห์ (อ่านก่อนใช้ตัดสินใจ)

1. ประวัติสั้น + n เล็ก: การขายจริงเริ่ม เม.ย. 2026 → repeat 8 คนจาก 338 — เป็น "สัญญาณต้น ๆ" ไม่ใช่ข้อสรุปนิ่ง
2. Utilization >100% ในบางกลุ่ม: โมเดล cycle เป็นราย user — user ที่ถือหลาย subscription ซ้อนกันจะทำให้ consumption ของ 2 แพ็ครวมเข้า cycle เดียว (เจอน้อย: กระทบ segment ② เป็นหลัก ~13 cycles)
3. รายได้เป็นประมาณการ: คิดจาก list price (priceThb) ไม่รวมส่วนลด/โปรโมชัน
4. Win-back 41 คน รวม trial→paid: ส่วนใหญ่คือ trial หมดอายุแล้วค่อยตัดสินใจซื้อ ไม่ใช่ paid churn ที่กลับมา
5. Left-censoring: subscription ที่เริ่มก่อน 1 ม.ค. 2026 มองไม่เห็นในข้อมูล
6. MonthlyReset ยังน้อย (23 events): segment "รอ reset" จึงเล็ก — จะแม่นขึ้นเมื่อระบบ recurring ทำงานนานขึ้น
